    **In DownloadController.php**, enforce tenant-scoped path validation. The actual file download endpoint is `backend/public/download.php` → `DownloadController::download()`. Changes to make:

    1. Change the UPLOAD_DIR constant to a method/property that incorporates the tenant context:
    ```php
    private function getAllowedUploadDir(): string
    {
        $tenantId = App\Config\TenantContext::getTenantId();
        return realpath(__DIR__ . '/../../uploads') . '/tenant-' . $tenantId;
    }
    ```

    2. Replace the existing realpath/UPLOAD_DIR check in `download()` with the tenant-scoped prefix:
    ```php
    $allowedDir = $this->getAllowedUploadDir();
    $realPath = realpath($filePath);

    if ($realPath === false || !str_starts_with($realPath, $allowedDir . '/') && $realPath !== $allowedDir) {
        throw new InvalidArgumentException('Access denied: file is outside tenant upload directory.');
    }
    ```

    3. Update `getFilePath()` to build paths within the tenant directory:
    ```php
    private function getFilePath(string $fileName): string
    {
        return $this->getAllowedUploadDir() . '/' . basename($fileName);
    }
    ```

    Extract the path-prefix validation logic into a testable protected/public method (e.g. `isWithinAllowedDir(string $realPath, string $allowedDir): bool`) so unit tests can call it directly without HTTP context.

    Create tests/Unit/Upload/ directory. Implement tests checking the path logic using TenantContext::initialize() for setup and TenantContext::reset() in tearDown.
