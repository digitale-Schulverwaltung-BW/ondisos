    Add TenantRepository::findAll(): array — returns all active tenants ordered by name:
    SELECT id, name, slug FROM tenants WHERE active = 1 ORDER BY name ASC

    In index.php (and/or a shared location like bootstrap.php or a new top-of-page handler), process the switch_tenant parameter. Place this after auth check, before data loading:

    ```php
    // Tenant switcher (platform admin only)
    if (($multiTenantEnabled ?? false) && !empty($_SESSION['is_platform_admin'])) {
        if (isset($_GET['switch_tenant'])) {
            $switchVal = (int)$_GET['switch_tenant'];
            if ($switchVal === 0) {
                // Switch to "All tenants" view
                unset($_SESSION['switched_tenant_id']);
                App\Config\TenantContext::initAllTenants();
            } else {
                // Switch to specific tenant
                $_SESSION['switched_tenant_id'] = $switchVal;
                App\Config\TenantContext::initialize($switchVal);
            }
            // Redirect to clean URL (remove switch_tenant from query string)
            $cleanUrl = strtok($_SERVER['REQUEST_URI'], '?');
            header('Location: ' . $cleanUrl);
            exit;
        }
    }
    ```

    This switch handler must run after bootstrap.php (TenantContext already set from session) but override it for this request. The redirect-after-POST pattern (PRG) prevents double-switching on refresh.

    Consider if this logic belongs in index.php alone or in every admin page. For now, add to index.php — Platform admin typically lands on index.php. If needed in detail.php/trash.php, that's a follow-up.
