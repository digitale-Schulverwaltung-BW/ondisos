    In bootstrap.php, replace the `// Phase 2: else { resolve tenant from session or API key }` comment (line 52) with the full else branch per Pattern 2 in RESEARCH.md:

    ```php
    } else {
        $isApiRequest = defined('API_REQUEST') && API_REQUEST === true;

        if ($isApiRequest) {
            $slug = $_GET['tenant'] ?? $_POST['tenant'] ?? '';
            if (!empty($slug)) {
                $tenantRepo = new App\Repositories\TenantRepository();
                $tenant = $tenantRepo->findBySlug($slug);
                if ($tenant && (bool)$tenant['active']) {
                    App\Config\TenantContext::initialize((int)$tenant['id']);
                }
            }
            // If slug invalid/inactive: TenantContext stays uninitialized → endpoint will return 401
        } else {
            // Browser request: resolve from session
            if (!empty($_SESSION['is_platform_admin'])) {
                $switchedTenantId = $_SESSION['switched_tenant_id'] ?? null;
                if ($switchedTenantId !== null) {
                    App\Config\TenantContext::initialize((int)$switchedTenantId);
                } else {
                    App\Config\TenantContext::initAllTenants();
                }
            } elseif (!empty($_SESSION['tenant_id'])) {
                App\Config\TenantContext::initialize((int)$_SESSION['tenant_id']);
            }
            // Else: TenantContext uninitialized — auth.php will redirect to login
        }
    }
    ```

    Note: session_start() must be called before this block for session vars to be available. bootstrap.php currently does not start sessions (auth.php does). Add session_start() to bootstrap.php guarded by: `if (php_sapi_name() !== 'cli' && session_status() === PHP_SESSION_NONE) { session_start(); }`

    In auth.php, after the existing admin_logged_in + session timeout checks, add:
    ```php
    // Multi-tenant: verify tenant context is correctly set for this session
    if ($multiTenantEnabled) {
        $isPlatformAdmin = $_SESSION['is_platform_admin'] ?? false;
        $hasTenantId = !empty($_SESSION['tenant_id']);

        if (!$isPlatformAdmin && !$hasTenantId) {
            // Logged in but no tenant context — data integrity error, force re-login
            session_regenerate_id(true);
            session_destroy();
            header('Location: login.php');
            exit;
        }
    }
    ```

    Also add the MULTI_TENANT_ENABLED=true forces auth check: if $multiTenantEnabled is true and user is not logged in, redirect to login regardless of AUTH_ENABLED value.
