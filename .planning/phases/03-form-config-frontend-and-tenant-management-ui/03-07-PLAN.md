    Create backend/seed-forms.php as a CLI-only script. Structure:

    1. CLI guard: `if (php_sapi_name() !== 'cli') { http_response_code(403); exit("Nur per CLI ausführbar.\n"); }`

    2. Bootstrap: load EnvLoader and Database (same approach as migrate.php — read migrate.php to see exact require paths and initialization pattern).

    3. Define config file paths to check:
       ```php
       $paths = [
           __DIR__ . '/../frontend/config/forms-config.php',
           __DIR__ . '/config/forms-config.php',
       ];
       ```

    4. For each path: if file exists, `require` it to get array, iterate entries, insert. Track which paths were seeded.

    5. For each form entry ($key => $config):
       - json_encode with JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT
       - INSERT IGNORE INTO form_configs (tenant_id, form_key, config_json) VALUES (1, ?, ?)
       - Output: "Seeded: $key (from $path)\n" or "Skipped (already exists): $key\n" (check affected_rows after INSERT IGNORE)

    6. If no config files found: print warning and exit 0 (not error — may already be seeded).

    7. After all inserts: print summary and reminder:
       ```
       Done. X form(s) seeded for tenant_id=1.

       NEXT STEPS:
       1. Verify form_configs table: SELECT * FROM form_configs WHERE tenant_id=1;
       2. Delete forms-config.php files:
          - rm frontend/config/forms-config.php
          - rm backend/config/forms-config.php  (if exists)
       3. Do NOT run seed-forms.php again after deletion.
       ```

    8. Wrap entire DB operation in try/catch — on exception, print error and exit(1).

    Use declare(strict_types=1). Pure PHP, no Composer autoloader needed (require_once the config files directly like migrate.php does).
