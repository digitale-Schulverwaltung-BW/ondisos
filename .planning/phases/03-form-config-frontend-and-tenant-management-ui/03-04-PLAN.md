  <action>
    Create backend/public/tenants.php with the page guard, all POST handlers, and the list view with create form. Task 2 will add the edit view and admin management section.

    **Page guard (top of file):**
    ```php
    declare(strict_types=1);
    require_once __DIR__ . '/../inc/bootstrap.php';
    use App\Repositories\TenantRepository;
    use App\Repositories\TenantAdminRepository;
    use App\Utils\CsrfProtection; // check actual class name in existing pages

    if (empty($_SESSION['is_platform_admin'])) {
        http_response_code(403);
        die('Zugriff nur für Plattform-Admins.');
    }
    ```

    **Routing logic:**
    - `$id = isset($_GET['id']) ? (int)$_GET['id'] : null;`
    - `$action = $_POST['action'] ?? null;` for POST handling
    - Process POST before any HTML output (PRG pattern)

    **POST handlers (before HTML output):**

    1. `action=create_tenant`:
       - Validate name (required, max 255), slug (required, max 100, URL-safe chars only)
       - Generate API secret: `$apiSecret = bin2hex(openssl_random_pseudo_bytes(32));`
       - Call `$tenantRepo->create(['name' => $name, 'slug' => $slug, 'origin' => $origin ?: null, 'api_secret' => $apiSecret])`
       - On success: store new tenant id + API secret in session flash, redirect to `tenants.php?id={newId}&created=1`
       - On InvalidArgumentException (slug conflict): set $error, render form with error

    2. `action=update_tenant` (with `?id=N`):
       - Update name, origin, active from POST
       - Call `$tenantRepo->update($id, [...])`
       - Redirect to `tenants.php?id={id}&saved=1`

    3. `action=regenerate_secret` (with `?id=N`):
       - Generate new API secret: `$newSecret = bin2hex(openssl_random_pseudo_bytes(32));`
       - Call `$tenantRepo->updateApiSecret($id, $newSecret)` — MUST use updateApiSecret(), NOT update().
         update() whitelist excludes api_secret by design; update() would silently ignore the secret field.
       - Store new secret in session flash, redirect to `tenants.php?id={id}&secret_regenerated=1`

    4. `action=create_admin` (with `?id=N` = tenant_id):
       - Hash password: `password_hash($plain, PASSWORD_BCRYPT)`
       - Call `$adminRepo->create(['tenant_id' => $id, 'username' => $username, 'password_hash' => $hash])`
       - On success: store plain password in session flash, redirect to `tenants.php?id={id}&admin_created=1`
       - On InvalidArgumentException (username conflict): set $error

    5. `action=toggle_admin` (with admin_id and active=0|1):
       - Call `$adminRepo->toggleActive($adminId, (bool)$_POST['active'])`
       - Redirect to `tenants.php?id={id}`

    6. `action=reset_password` (with admin_id):
       - Hash new password, call `$adminRepo->resetPassword($adminId, $hash)`
       - Store plain password in session flash, redirect to `tenants.php?id={id}&password_reset=1`

    **Flash session pattern:**
    Use `$_SESSION['flash']` array, read and clear at top of page render. Store: new_api_secret, new_password, admin_username.

    **List view (when $id === null):**
    - `$tenants = $tenantRepo->findAllForAdmin()`
    - Bootstrap 5 table: columns = Name (linked to `?id={id}`), Slug, Status badge (green/red)
    - "Neuen Tenant erstellen" button opens a create form below (or inline form on same page)
    - Create form fields: Name (text), Slug (text, auto-filled from name via JS, URL-safe only), CORS Origin (text, optional)
    - No db or created_at columns per CONTEXT.md
    - Include slug auto-fill JS at bottom of list view

    Include `require_once __DIR__ . '/../inc/header.php';` and `require_once __DIR__ . '/../inc/footer.php';` wrapping the HTML output.

    Follow Bootstrap 5 markup exactly as used in existing admin pages (same table classes, form classes, button variants as index.php/detail.php).

    Note: Check existing pages (bulk_actions.php, detail.php) for the exact CsrfProtection method names used (csrfField() vs tokenField() vs inline hidden input pattern).
