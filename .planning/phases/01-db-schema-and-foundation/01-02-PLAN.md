  <action>
    Create backend/migrate.php implementing the complete v2.6 → v3.0 migration.

    **Required structure (in order):**

    1. CLI-only guard at the very top:
       ```php
       if (php_sapi_name() !== 'cli') {
           http_response_code(403);
           exit("This script may only be run from the command line.\n");
       }
       ```

    2. Load autoloader: require_once __DIR__ . '/vendor/autoload.php'

    3. Verify .env exists; if not: fwrite(STDERR, ...) and exit(1)

    4. EnvLoader::load($envFile)

    5. Read API_SECRET_KEY via EnvLoader::get('API_SECRET_KEY'). If empty: fwrite(STDERR, "Error: API_SECRET_KEY not set in .env\n") and exit(1)

    6. Connect: Database::getConnection() in try/catch; on RuntimeException: fwrite(STDERR, "Error: Cannot connect to database — {$e->getMessage()}\n") and exit(1)

    7. Migration steps in this exact order (each prints "Step N: Description... " then "OK\n" or "SKIPPED (reason)\n"):

       **Step 1: Create tenants table (IF NOT EXISTS)**
       ```sql
       CREATE TABLE IF NOT EXISTS tenants (
           id INT AUTO_INCREMENT PRIMARY KEY,
           name VARCHAR(255) NOT NULL,
           api_secret VARCHAR(255) NOT NULL,
           active TINYINT(1) DEFAULT 1,
           created_at DATETIME DEFAULT CURRENT_TIMESTAMP
       ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
       ```

       **Step 2: Create tenant_admins table (IF NOT EXISTS)**
       ```sql
       CREATE TABLE IF NOT EXISTS tenant_admins (
           id INT AUTO_INCREMENT PRIMARY KEY,
           tenant_id INT NOT NULL,
           username VARCHAR(100) NOT NULL,
           password_hash VARCHAR(255) NOT NULL,
           is_platform_admin TINYINT(1) DEFAULT 0,
           created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
           UNIQUE KEY uq_tenant_username (tenant_id, username),
           FOREIGN KEY fk_tenant_admin_tenant (tenant_id)
               REFERENCES tenants(id) ON DELETE CASCADE
       ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
       ```

       **Step 3: Create form_configs table (IF NOT EXISTS)**
       ```sql
       CREATE TABLE IF NOT EXISTS form_configs (
           id INT AUTO_INCREMENT PRIMARY KEY,
           tenant_id INT NOT NULL,
           form_key VARCHAR(100) NOT NULL,
           config_json LONGTEXT NOT NULL,
           created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
           updated_at DATETIME NULL ON UPDATE CURRENT_TIMESTAMP,
           UNIQUE KEY uq_tenant_form (tenant_id, form_key),
           FOREIGN KEY fk_form_config_tenant (tenant_id)
               REFERENCES tenants(id) ON DELETE CASCADE
       ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
       ```

       **Step 4: Seed default tenant (INSERT IGNORE, prepared statement)**
       Use $db->prepare("INSERT IGNORE INTO tenants (id, name, api_secret, active, created_at) VALUES (1, 'Default', ?, 1, NOW())")
       Bind $apiSecret. Print "OK\n" if affected_rows > 0, "SKIPPED (already exists)\n" otherwise.

       **Step 5: Add tenant_id column to anmeldungen (idempotent via INFORMATION_SCHEMA)**
       Use $dbName = App\Config\EnvLoader::require('DB_NAME') for the schema name — do NOT use DATABASE() function.
       ```php
       $stmt = $db->prepare(
           "SELECT COUNT(*) as cnt FROM INFORMATION_SCHEMA.COLUMNS
            WHERE TABLE_SCHEMA = ? AND TABLE_NAME = 'anmeldungen' AND COLUMN_NAME = 'tenant_id'"
       );
       $stmt->bind_param('s', $dbName);
       $stmt->execute();
       $row = $stmt->get_result()->fetch_assoc();
       ```
       If cnt === 0: run ALTER TABLE anmeldungen ADD COLUMN tenant_id INT NOT NULL DEFAULT 1; print "OK\n"
       If cnt > 0: print "SKIPPED (already exists)\n"

       **Step 6: Add indexes on anmeldungen.tenant_id (idempotent via INFORMATION_SCHEMA)**
       Check INFORMATION_SCHEMA.STATISTICS for each index name before adding:
       - idx_tenant (tenant_id)
       - idx_tenant_formular (tenant_id, formular)
       - idx_tenant_status (tenant_id, status)

       For each: check if index exists in INFORMATION_SCHEMA.STATISTICS WHERE TABLE_SCHEMA=? AND TABLE_NAME='anmeldungen' AND INDEX_NAME=?
       If not exists: ALTER TABLE anmeldungen ADD INDEX {name} (...); print "OK\n"
       If exists: print "SKIPPED (already exists)\n"

       **Step 7: Add foreign key anmeldungen → tenants (idempotent via INFORMATION_SCHEMA)**
       Check INFORMATION_SCHEMA.TABLE_CONSTRAINTS WHERE CONSTRAINT_SCHEMA=? AND TABLE_NAME='anmeldungen' AND CONSTRAINT_NAME='fk_anmeldung_tenant'
       If not exists: ALTER TABLE anmeldungen ADD CONSTRAINT fk_anmeldung_tenant FOREIGN KEY (tenant_id) REFERENCES tenants(id); print "OK\n"
       If exists: print "SKIPPED (already exists)\n"

    8. Print "Migration complete.\n" at the end.

    **Style conventions:**
    - declare(strict_types=1) at top (after CLI guard — the guard must be before declare for web-safe exit)
    - Actually, CLI guard must come after <?php tag but the declare must still be present. Structure: <?php, declare, CLI guard.
    - All SQL DDL via $db->query() is acceptable. All inserts/selects with user-supplied values via $db->prepare() + bind_param().
    - No try/catch around individual steps — a failed step throws via the error handler set in bootstrap (but bootstrap is NOT loaded here). Wrap the whole migration body in a try/catch that prints the error and exits(1).
